# 2become1 skills

Practical notes for the arrangement DAW. The application behavior they describe is `cbe6984` on `main`. Read the skill that matches the surface, then trust the code and `AGENTS.md` when a note is older than the file.

The Producer ranks and plans from measurements. It does not hear the music. The local language-model path is optional. On this machine `llama-server` segfaults because the NVIDIA kernel module and userspace disagree, and that stack is left unchanged. The latest autonomous arrangement still needs the PM listening steps in `docs/the-maestro.md`.

| Skill | Use it for |
| --- | --- |
| [black-tie-daw](black-tie-daw/SKILL.md) | Eight-lane editing, source slip, trim, fades, pitch, stretch, EQ |
| [clockwork-audio](clockwork-audio/SKILL.md) | Transport, Stop, Draw Levels, live playback against WAV export |
| [musical-analysis](musical-analysis/SKILL.md) | Section fingerprints and chorus ranking |
| [autonomous-producer](autonomous-producer/SKILL.md) | Take the decks, human takeover, remembered plans |
| [audio-validation](audio-validation/SKILL.md) | Negative controls and export evidence |
| [release-gates](release-gates/SKILL.md) | Worktree tests, fast-forward promotion, disk |

These notes do not accept the music. The PM listening steps are in `docs/the-maestro.md`. Contributor handoffs that were not written by that agent are in [contributor-handoffs.md](contributor-handoffs.md).
